# SagejournalApp

Importez vos journaux Excel ou CSV, vérifiez les écritures et lancez la saisie dans Sage.

## Installation

1. Ouvrez la [page de téléchargement](https://github.com/anasouaj/SagejournalApp-Releases/releases/latest).
2. Téléchargez le fichier **SagejournalApp-…-Setup.exe** et lancez-le.
3. Suivez les étapes, puis ouvrez SagejournalApp depuis le menu Démarrer.
4. Dans **Licence / Activation**, saisissez la clé reçue du propriétaire.

Windows 10/11 64 bits, une installation Sage compatible et une connexion Internet sont nécessaires.
Python et Excel ne sont pas nécessaires.

## Utilisation

Cliquez sur **+ Importer**, vérifiez les colonnes et les écritures, puis choisissez **Saisir dans Sage**.
Les journaux sont enregistrés automatiquement. Vérifiez le journal et la période dans Sage avant la saisie, puis les écritures obtenues après celle-ci.

## Mises à jour

Ouvrez **··· → Mises à jour → Vérifier en ligne**, puis cliquez sur **Installer et redémarrer** si une nouvelle version est disponible.
Terminez toute saisie Sage en cours avant la mise à jour. Vos journaux et votre licence sont conservés.
